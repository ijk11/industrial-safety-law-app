# 법령 데이터 스키마

법령 하나당 JSON 파일 하나 (`/data/laws/{법령명}.json`).

```json
{
  "법령명": "산업안전보건법",
  "법령구분": "법률",
  "법령번호": "제21374호",
  "공포일": "2026-02-03",
  "시행일": "2026-08-01",
  "출처": "국가법령정보센터 PDF (URL, 다운로드일)",
  "조문": [
    {
      "조번호": "제1조",
      "제목": "목적",
      "장": "제1장 총칙",
      "본문": "이 법은 ...",
      "항": [
        { "번호": "①", "내용": "...", "호": ["1. ...", "2. ..."] }
      ],
      "참조조문": ["제2조"],
      "개정이력": ["2024-05-17 일부개정"]
    }
  ]
}
```

- 조문에 항(①②③)이 없으면 "항" 필드 생략, 본문만 채운다.
- 호(1. 2. 3.) 아래에 목(가. 나. 다.)이 있으면 문자열에 그대로 포함한다 (예: "1. ... 가. ... 나. ...").
- 반드시 원문 그대로 옮긴다 (요약/의역 금지). 숫자, 조사, 띄어쓰기까지 원문과 동일해야 한다.
- 조문 번호가 중간에 비어있으면(삭제된 조문) `"삭제": true`로 표시하고 본문은 생략.
