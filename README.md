# 산안법 조문 찾기

산업안전보건법·중대재해처벌법 체계 전체를 폰에 담아 두고 인터넷 없이 찾는 앱.
현장에서 조문 번호나 낱말 몇 개로 원문을 바로 꺼내 보려고 만들었다.

- **완전 오프라인** — 원문 10.9MB를 앱 안에 넣어 두고 기기에서 펼친다. 실행 중 바깥 통신 없음
- **아이폰 홈 화면 설치** — 사파리에서 열고 `공유 → 홈 화면에 추가`
- **내려받기 2.4MB** — 첫 실행 한 번만. 그 뒤로는 비행기모드에서도 열린다

중대재해처벌법은 하위법령이 시행령 하나뿐이다 (시행규칙이 없다).
근로감독관 집무규정은 고시가 아니라 훈령이지만, 감독·범죄인지·과태료의 실제 잣대라 함께 담았다.
고시는 실무에서 자주 드는 것으로 골랐다 — MSDS·분류표시 기준, 노출기준, 위험성평가 지침,
안전보건교육규정, 안전검사, 안전인증(방호장치·보호구·위험기계), 공정안전보고서,
유해위험방지계획서, 건설업 산업안전보건관리비, 작업환경측정, 건강진단, 근골격계, 석면 등.

목록을 바꾸려면 [`scripts/fetch_laws.py`](scripts/fetch_laws.py)의 `LAWS` · `NOTICES`를 고치고 다시 받으면 된다.
고시는 그것으로 끝이지만, **법령(`LAWS`)은 [`scripts/build_app.py`](scripts/build_app.py)의 `LEVELS`에도
한 줄 넣어야 한다** — 배지·색 단계·필터 묶음·계열이 거기서 정해지고, 없으면 앱에 실리지 않는다.
계열이 다른 법을 넣었다면 [`scripts/app_template.html`](scripts/app_template.html)의 `FAMILY_DOC`도 함께 봐야
「법 제4조」 같은 인용이 제 법으로 간다. 줄여 부르는 이름은 `ALIAS`(검색)와 `NAMED_DOC`(인용)에 적는다.

## 쓰는 법

| 하고 싶은 것 | 입력 |
|---|---|
| 조문 번호로 바로 | `38` · `제38조` · `38조의2` |
| 법령을 짚어서 | `령 16` · `칙 3` · `기준 619` · `중대재해 4` · `감독규정 16` |
| 법령을 통째로 | `중대재해처벌법` · `집무규정` (이름만 치면 그 법령이 차례로 나온다) |
| 별표 | `별표 3` |
| 낱말로 | `추락 방지` (띄어쓴 낱말 모두 포함) |

조문 안의 `제63조`, `법 제38조`, `별표 1` 같은 인용은 눌러서 이동하고, 뒤로가기로 돌아온다.
탭 이동·목차·이전다음도 모두 뒤로가기가 듣는다. 홈 화면에 설치하면 브라우저 뒤로가기 버튼이
없으므로, 화면 왼쪽 끝을 쓸어넘기는 제스처가 뒤로가기다.
아래 세 칸은 **검색 / 목차 / 기타**다.

낱말로 찾아 들어간 조문에는 찾던 낱말이 형광펜으로 남는다. 머리의 형광펜을 누르면 걷힌다
(번호로 바로 찾아간 때는 칠하지 않는다). 검색을 비운 첫 화면에는 **책갈피해 둔 조문**이
먼저 오고, 많아지면 제목을 눌러 접을 수 있다. 그 아래가 최근 본 조문이다.

머리말 옆에 원문을 **언제 받아온 것인지**(기준일)가 늘 붙어 있다. 기타 탭 「법령 판 · 업데이트」에서
기준일·담긴 법령 수·가장 늦은 시행일·앱 판을 보고, `법령 업데이트 확인`으로 새 판을 직접
받아 바로 갈아탈 수 있다. 누르지 않아도 앱을 열면 저절로 받아 두지만, 그건 앱을 완전히
닫았다 열어야 반영된다.

## 조문 밑의 벌칙·과태료

산업안전보건법 조문을 열면 그 조문을 어겼을 때 무엇이 따라오는지가 항 밑에 붙는다.
항이 지정된 것은 그 항 밑에, 조 전체에 걸리는 것은 조문 맨 아래에 온다.

- **[형벌]** 징역·벌금 (법 제167조~제172조)
- **[과태료]** 무엇을 했을 때인지와 1·2·3차 금액 (법 제175조 + 시행령 [별표 35])

1·2·3차 금액은 법에 없고 **시행령 [별표 35] 개별기준**에만 있다. 그 표는 행 구분선 없이
1,086줄이 한 덩어리이고 칸이 여덟 칸뿐이라 일반 표 파서가 풀지 못해,
[`scripts/penalty.py`](scripts/penalty.py)가 따로 캔다. 경우별로 갈리는 것(제15조·제42조 등)은
한 줄로 접고 눌러서 편다.

담는 것은 **조문을 직접 위반한** 경우뿐이다. "~에 따른 명령을 위반한 자", 양벌규정(제173조),
가중처벌(제167조제2항), 이수명령(제174조)은 넣지 않는다 — 조문마다 같은 경고가 반복되면
본문을 가린다.

## 기타 탭

조문을 하나씩 여는 것만으로는 안 보이는 것을 가로질러 본다.

| 갈래 | 무엇 |
|---|---|
| 벌칙 모아보기 | 과태료·형벌이 걸린 조문을 장별로 (형벌은 제1~3장에 하나도 없다) |
| 규모별 의무 | 5명 미만부터 500명 이상까지, 이어진 눈금 위에. 건설공사는 공사금액으로 |
| 법령 판 · 업데이트 | 기준일·앱 판, 새 판 직접 받기, 업데이트 내역 |

**규모별 의무는 정리한 표다.** 효력은 원문에 있으므로 항목마다 근거 조문을 함께 달았고,
눌러서 바로 원문으로 간다. 근거가 하나라도 끊기면 스모크 테스트가 먼저 걸린다.
업종에 따라 50·100·300명으로 갈리는 것은 **가장 낮은 눈금**에 두고 그 사정을 적었다 —
높은 쪽에만 두면 해당하는데도 못 보고 지나친다.

## PC에서 열어 보려면

`web/index.html`을 **더블클릭하면 열리지 않는다.** 브라우저가 `file://`에서는 옆 파일(법령 데이터) 읽기를
막기 때문이다. 둘 중 하나로 본다.

```bash
python scripts/preview.py     # 작은 서버를 띄워 브라우저로 열어 준다 (권장)
```

또는 `dist/산안법-조문찾기.html` — 원문까지 한 파일에 다 들어 있어 더블클릭으로 열린다.
`web/`은 웹 주소에 올려야 동작하며, 그 대신 오프라인 캐시와 홈 화면 설치가 된다.

## 다시 만들기

```bash
python scripts/fetch_laws.py     # 국가법령정보 OPEN API에서 원문 수집 → data/
python scripts/build_fonts.py    # 글꼴 서브셋 (한 번만) → web/fonts/
python scripts/build_icons.py    # 아이콘 (한 번만)      → web/icons/
python scripts/build_splash.py   # 실행 화면 (한 번만)   → web/splash/
python scripts/build_pwa.py      # 앱 굽기               → web/
```

확인 — [`scripts/smoke_test.js`](scripts/smoke_test.js)의 116개 항목을 실제 브라우저에서 눌러 본다.
기능을 더하면 여기에도 검사를 더한다:

```bash
python scripts/verify.py --shots   # 크롬을 화면 없이 띄워 눌러 보고 화면도 찍는다
```

## 올리기

GitHub Pages에 자동으로 올라간다. 저장소에서 한 번만 켜 주면 된다.

**Settings → Pages → Build and deployment → Source** 를 `GitHub Actions` 로 바꾼다.
그 뒤로는 `main`에 푸시할 때마다 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)이
앱을 다시 굽고 올린다. 주소는 `https://ijk11.github.io/industrial-safety-law-app/`.

무료 플랜에서는 **저장소가 공개여야** Pages가 동작한다. 원문이 국가법령정보센터 공개 자료라
공개해도 문제는 없지만, 비공개로 두고 싶으면 아래 대안을 쓴다.

법이 개정되면 이것만 하면 된다.

```bash
python scripts/fetch_laws.py     # 원문 다시 받기 → data/
python scripts/build_pwa.py      # 앱 다시 굽기   → web/  (건너뛰어도 CI가 다시 굽는다)
git commit -am "법령 갱신" && git push
```

원문이 그대로면 다시 구워도 결과가 바이트까지 같다 — gzip을 `mtime=0`으로 굽기 때문이다.
그래서 법이 안 바뀐 푸시로는 서비스워커 캐시 이름이 그대로고, 폰이 1.6MB를 다시 받지 않는다.
원문이 바뀌면 캐시 이름이 함께 바뀌므로 앱을 닫았다 열면 새 판으로 갈린다.

글꼴·아이콘·실행 화면은 이미 `web/`에 구워져 저장소에 들어 있어 CI에서 다시 굽지 않는다.
새 글자가 생겼을 때만 로컬에서 `build_fonts.py`를 돌린다.

### 다른 데 올리려면

`web/` 폴더를 정적 호스팅에 통째로 올리면 끝이다. 서버도 빌드 설정도 필요 없다.
`https`여야 홈 화면 설치와 오프라인 캐시가 동작한다.

| | 비공개 저장소 | 대역폭 | 걸리는 것 |
|---|---|---|---|
| **GitHub Pages** | 유료 플랜만 | 100GB/월 | 저장소 설정 한 번 |
| Cloudflare Pages | 된다 | 무제한 | 계정 + 대시보드 설정 |
| Netlify Drop | 된다 (폴더 드래그) | 100GB/월 | 계정만 |
| Firebase Hosting | 된다 | 360MB/일 | **Node.js 설치** |

Cloudflare Pages는 비공개 저장소를 그대로 연결할 수 있다. 빌드 명령 `python scripts/build_pwa.py`,
출력 폴더 `web`으로 두면 푸시할 때마다 같은 방식으로 올라간다.
Firebase는 `firebase-tools`(npm)로만 배포되고 콘솔에 업로드 창이 없어 Node를 깔아야 한다.

검색엔진에는 `index.html`의 `noindex`로 막아 둔다. 주소를 아는 사람만 쓰는 용도다.
`web/robots.txt`도 넣어 두었지만, `github.io` 하위 주소에서는 크롤러가 저장소 밖의 루트
robots.txt를 보기 때문에 실제로 막는 것은 `noindex` 쪽이다.

## 만들면서 신경 쓴 것

- **표 정렬** — 별표의 괘선표는 `한글·괘선 = 라틴 2칸`이 지켜져야 칸이 맞는다. 나눔고딕코딩이 그 규격에
  정확히 맞지만 한자가 없어서, Noto Sans Mono CJK의 한자 433자를 폭 1000으로 옮겨 붙여 한 벌로 구웠다.
  실제 쓰는 1,823자만 남겨 255KB.
- **괘선표를 진짜 표로** — 별표의 표는 원문이 괘선 문자로 그려 놓은 것이라, 폰에서는 가로로 잘리고
  밀어 보면 어느 행이었는지 놓친다. 괘선 위치를 표시열로 읽어 행·열로 풀고 HTML 표로 다시 그린다.
  480건 중 177건이 풀린다. 원문이 칸을 넘겨 세로선이 밀린 표가 많아 가까운 경계로 붙여 읽되,
  칸 안에 표가 또 그려진 것(63건)이나 테두리가 끊긴 것은 손대지 않고 원문 그대로 둔다.
  푼 뒤에 글자를 세어 원문과 대조한다 — 한 자라도 어긋나면 원문으로 되돌린다.

- **인용을 어느 법으로 보내는가** — 조문 속의 `제38조`는 눌러서 넘어갈 수 있어야 하지만, 그 앞에 붙은
  이름을 봐야 어디로 보낼지 정해진다. `법`·`영` 처럼 짧게 부른 이름은 **읽고 있는 법령의 계열 안에서**
  푼다 — 중대재해처벌법 시행령의 「법 제4조」는 산안법이 아니라 중대재해처벌법이다.
  `같은 법`은 그 앞에서 마지막으로 부른 법을 가리키고(「화학물질관리법」… `같은 법 제3조`),
  `이 규칙`은 지금 읽고 있는 그 법령이다. 담지 않은 법을 부른 인용(`진폐법 제5조`)은 링크하지 않는다 —
  엉뚱한 조문으로 보내느니 그냥 두는 편이 낫다. 별표 인용도 같은 규칙으로 푼다
  (시행규칙 안의 `영 별표 7`은 시행령의 별표 7이다).
  `…라 한다)이 법 제64조`의 `이`는 관형사가 아니라 주격조사라, 앞에 띄어쓰기가 있을 때만 `이 법`으로 읽는다.

- **표가 아닌 별표** — 579건 중 99건은 표가 아니라 글을 상자에 넣어 둔 것이거나 괘선이 아예 없다.
  그런 것은 괘선 장식만 걷어내 비례 글꼴로 흘려 폰 너비에 맞춘다. 줄바꿈은 손대지 않는다 —
  원문이 칸에 맞춰 접어 둔 자리에 공백이 있었는지가 데이터에 남아 있지 않아(줄 끝 공백이 전부
  잘려 있다), 도로 이으면 「해당 지정기관」이 「해당지정기관」이 된다. 진짜 표 480건은 칸이
  맞아야 하므로 손대지 않는다. 벗겨 낸 뒤에도 괘선이 남으면 표를 잘못 본 것이므로 원문으로 되돌린다.
- **고시 계층 복원** — API가 고시 본문의 항·호·목을 한 줄로 붙여 준다. 순번이 이어질 때만 자르고,
  목은 그 호가 "각 목"을 예고했을 때만 나눈다. `하여야 한다.`의 `다.`를 목 기호로 오인하지 않기 위해서다.
- **첫 화면이 먼저 뜬다** — `index.html`은 44KB뿐이고 원문은 따로 받는다.
- **실행 화면** — iOS는 splash 이미지가 없으면 열 때 흰 화면이 번쩍인다. 기기 크기별로 밝은 판·어두운 판을
  그려 두되, 색이 몇 가지뿐이라 팔레트 PNG로 저장해 18장 304KB에 맞췄다.

## 출처와 한계

원문은 [국가법령정보센터](https://www.law.go.kr) OPEN API에서 받은 그대로다. 요약하거나 고치지 않았다.
다만 **법적 효력은 원문에 있다.** 조문 화면 아래 `원문 확인`으로 개정 여부를 확인할 것.
별표 중 별지 서식은 원본이 이미지·HWP라 표 텍스트만 담긴 경우가 있다.
