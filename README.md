# 산안법 조문 찾기

산업안전보건법 체계 전체를 폰에 담아 두고 인터넷 없이 찾는 앱.
현장에서 조문 번호나 낱말 몇 개로 원문을 바로 꺼내 보려고 만들었다.

- **완전 오프라인** — 원문 11.6MB를 앱 안에 넣어 두고 기기에서 펼친다. 실행 중 바깥 통신 없음
- **아이폰 홈 화면 설치** — 사파리에서 열고 `공유 → 홈 화면에 추가`
- **내려받기 2.0MB** — 첫 실행 한 번만. 그 뒤로는 비행기모드에서도 열린다

## 담긴 법령 (29건 · 조문 1,981개 · 별표 551개)

| 배지 | 문서 | 조문 | 별표 |
|---|---|---:|---:|
| 법 | 산업안전보건법 | 184 | – |
| 령 | 산업안전보건법 시행령 | 125 | 35 |
| 칙 | 산업안전보건법 시행규칙 | 252 | 138 |
| 기준 | 산업안전보건기준에 관한 규칙 | 690 | 23 |
| 취업제한 | 유해·위험작업의 취업 제한에 관한 규칙 | 14 | 17 |
| 고시 | 고용노동부 고시·예규 24건 | 716 | 338 |

고시는 실무에서 자주 드는 것으로 골랐다 — MSDS·분류표시 기준, 노출기준, 위험성평가 지침,
안전보건교육규정, 안전검사, 안전인증(방호장치·보호구·위험기계), 공정안전보고서,
유해위험방지계획서, 건설업 산업안전보건관리비, 작업환경측정, 건강진단, 근골격계, 석면 등.

목록을 바꾸려면 [`scripts/fetch_laws.py`](scripts/fetch_laws.py)의 `LAWS` · `NOTICES`를 고치고 다시 받으면 된다.

## 쓰는 법

| 하고 싶은 것 | 입력 |
|---|---|
| 조문 번호로 바로 | `38` · `제38조` · `38조의2` |
| 법령을 짚어서 | `령 16` · `칙 3` · `기준 619` |
| 별표 | `별표 3` |
| 낱말로 | `추락 방지` (띄어쓴 낱말 모두 포함) |

조문 안의 `제63조`, `법 제38조`, `별표 1` 같은 인용은 눌러서 이동하고, 뒤로가기로 돌아온다.
탭 이동·목차·이전다음도 모두 뒤로가기가 듣는다. 홈 화면에 설치하면 브라우저 뒤로가기 버튼이
없으므로, 화면 왼쪽 끝을 쓸어넘기는 제스처가 뒤로가기다.
아래 세 칸은 검색 / 목차(장·절 트리) / 저장(책갈피·최근 본 조문).

머리말 옆에 원문을 **언제 받아온 것인지**(기준일)가 늘 붙어 있다. 저장 탭 맨 아래 「법령 판」에서
기준일·담긴 법령 수·가장 늦은 시행일·앱 판을 보고, `법령 업데이트 확인`으로 새 판을 직접
받아 바로 갈아탈 수 있다. 누르지 않아도 앱을 열면 저절로 받아 두지만, 그건 앱을 완전히
닫았다 열어야 반영된다.

## PC에서 열어 보려면

`web/index.html`을 **더블클릭하면 열리지 않는다.** 브라우저가 `file://`에서는 옆 파일(법령 데이터) 읽기를
막기 때문이다. 둘 중 하나로 본다.

```bash
python scripts/preview.py     # 작은 서버를 띄워 브라우저로 열어 준다 (권장)
```

또는 `dist/산안법-조문찾기.html` — 원문까지 한 파일에 다 들어 있어 더블클릭으로 열린다.
`web/`은 웹 주소에 올려야 동작하며, 그 대신 오프라인 캐시와 홈 화면 설치가 된다.

## 다시 만들기

```bash
python scripts/fetch_laws.py     # 국가법령정보 OPEN API에서 원문 수집 → data/
python scripts/build_fonts.py    # 글꼴 서브셋 (한 번만) → web/fonts/
python scripts/build_icons.py    # 아이콘 (한 번만)      → web/icons/
python scripts/build_splash.py   # 실행 화면 (한 번만)   → web/splash/
python scripts/build_pwa.py      # 앱 굽기               → web/
```

확인:

```bash
python scripts/verify.py --shots   # 크롬을 화면 없이 띄워 25개 항목을 눌러 보고 화면도 찍는다
```

## 올리기

GitHub Pages에 자동으로 올라간다. 저장소에서 한 번만 켜 주면 된다.

**Settings → Pages → Build and deployment → Source** 를 `GitHub Actions` 로 바꾼다.
그 뒤로는 `main`에 푸시할 때마다 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)이
앱을 다시 굽고 올린다. 주소는 `https://thenewij.github.io/industrial-safety-law-app/`.

무료 플랜에서는 **저장소가 공개여야** Pages가 동작한다. 원문이 국가법령정보센터 공개 자료라
공개해도 문제는 없지만, 비공개로 두고 싶으면 아래 대안을 쓴다.

법이 개정되면 이것만 하면 된다.

```bash
python scripts/fetch_laws.py     # 원문 다시 받기 → data/
python scripts/build_pwa.py      # 앱 다시 굽기   → web/  (건너뛰어도 CI가 다시 굽는다)
git commit -am "법령 갱신" && git push
```

원문이 그대로면 다시 구워도 결과가 바이트까지 같다 — gzip을 `mtime=0`으로 굽기 때문이다.
그래서 법이 안 바뀐 푸시로는 서비스워커 캐시 이름이 그대로고, 폰이 1.6MB를 다시 받지 않는다.
원문이 바뀌면 캐시 이름이 함께 바뀌므로 앱을 닫았다 열면 새 판으로 갈린다.

글꼴·아이콘·실행 화면은 이미 `web/`에 구워져 저장소에 들어 있어 CI에서 다시 굽지 않는다.
새 글자가 생겼을 때만 로컬에서 `build_fonts.py`를 돌린다.

### 다른 데 올리려면

`web/` 폴더를 정적 호스팅에 통째로 올리면 끝이다. 서버도 빌드 설정도 필요 없다.
`https`여야 홈 화면 설치와 오프라인 캐시가 동작한다.

| | 비공개 저장소 | 대역폭 | 걸리는 것 |
|---|---|---|---|
| **GitHub Pages** | 유료 플랜만 | 100GB/월 | 저장소 설정 한 번 |
| Cloudflare Pages | 된다 | 무제한 | 계정 + 대시보드 설정 |
| Netlify Drop | 된다 (폴더 드래그) | 100GB/월 | 계정만 |
| Firebase Hosting | 된다 | 360MB/일 | **Node.js 설치** |

Cloudflare Pages는 비공개 저장소를 그대로 연결할 수 있다. 빌드 명령 `python scripts/build_pwa.py`,
출력 폴더 `web`으로 두면 푸시할 때마다 같은 방식으로 올라간다.
Firebase는 `firebase-tools`(npm)로만 배포되고 콘솔에 업로드 창이 없어 Node를 깔아야 한다.

검색엔진에는 `index.html`의 `noindex`로 막아 둔다. 주소를 아는 사람만 쓰는 용도다.
`web/robots.txt`도 넣어 두었지만, `github.io` 하위 주소에서는 크롤러가 저장소 밖의 루트
robots.txt를 보기 때문에 실제로 막는 것은 `noindex` 쪽이다.

### 함께 쓰는 사람에게 보낼 안내

> 산업안전보건법 찾는 앱이야. 아이폰에서 **사파리로** 아래 주소를 열고,
> 아래쪽 공유 버튼(↑) → **홈 화면에 추가** 를 누르면 앱처럼 깔려.

> 조문 번호(`38`)나 낱말(`추락 방지`)로 찾으면 되고, 「제63조」 같은 인용은 눌러서 넘어가.

## 만들면서 신경 쓴 것

- **표 정렬** — 별표의 괘선표는 `한글·괘선 = 라틴 2칸`이 지켜져야 칸이 맞는다. 나눔고딕코딩이 그 규격에
  정확히 맞지만 한자가 없어서, Noto Sans Mono CJK의 한자 421자를 폭 1000으로 옮겨 붙여 한 벌로 구웠다.
  실제 쓰는 1,803자만 남겨 253KB.
- **고시 계층 복원** — API가 고시 본문의 항·호·목을 한 줄로 붙여 준다. 순번이 이어질 때만 자르고,
  목은 그 호가 "각 목"을 예고했을 때만 나눈다. `하여야 한다.`의 `다.`를 목 기호로 오인하지 않기 위해서다.
- **첫 화면이 먼저 뜬다** — `index.html`은 44KB뿐이고 원문은 따로 받는다.
- **실행 화면** — iOS는 splash 이미지가 없으면 열 때 흰 화면이 번쩍인다. 기기 크기별로 밝은 판·어두운 판을
  그려 두되, 색이 몇 가지뿐이라 팔레트 PNG로 저장해 18장 304KB에 맞췄다.

## 출처와 한계

원문은 [국가법령정보센터](https://www.law.go.kr) OPEN API에서 받은 그대로다. 요약하거나 고치지 않았다.
다만 **법적 효력은 원문에 있다.** 조문 화면 아래 `원문 확인`으로 개정 여부를 확인할 것.
별표 중 별지 서식은 원본이 이미지·HWP라 표 텍스트만 담긴 경우가 있다.
